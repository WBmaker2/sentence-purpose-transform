# 문장 목적 변환소

초등 5~6학년 국어 학습자를 위한 정적 React 웹앱입니다. 하나의 가상 학교 소식을 사실 그대로 보존하면서, 알리기·안내하기·설득하기·부탁하기 목적과 독자에 맞게 다시 표현해 봅니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버는 Vite로 실행됩니다. 배포용 산출물은 다음 명령으로 확인할 수 있습니다.

```bash
npm test
npm run build
npm run preview
```

## 학습 흐름

1. 사실 금고에서 시간·장소·수량·조건처럼 반드시 보존할 사실을 잠급니다.
2. 목적과 독자를 선택합니다. 준비되지 않은 목적·독자 조합은 선택지에서 제외됩니다.
3. 표현 조각을 골라 문장을 만들고 순서·삭제·되돌리기를 사용합니다.
4. 사실 보존과 목적 필수 요소를 모두 통과해야 효과 비교로 이동합니다.
5. 근거 틀을 채우고 변환 결과를 확인합니다. 결과는 필요할 때만 텍스트로 복사합니다.

미션 5에서는 같은 사실을 네 목적에 맞게 변환한 뒤, 가장 효과적인 결과와 선택 이유를 제출해야 완료됩니다.

## 제품 경계

- 백엔드, 로그인, 학생 이름, 개인정보를 사용하지 않습니다.
- 기본 상태는 브라우저 새로고침 시 초기화됩니다.
- 실제 학교 공지가 아닌 앱에 포함된 가상 사실만 사용합니다.
- 클립보드 복사는 사용자가 누를 때만 실행되며, 브라우저가 지원하지 않으면 화면에서 직접 복사할 수 있도록 안내합니다.

## 검증 기준

- `npm test`: 목적 판정, 학습 게이트, 미션 5 완료 조건, 콘텐츠 사실 연결 계약을 검증합니다.
- `npm run build`: TypeScript strict 검사와 Vite 정적 산출물 생성을 검증합니다.
- 브라우저 QA: 미션 1 전체 학습 경로, 제안 없는 설득 차단, 미션 5 최종 제출, 390px 가로 스크롤·콘솔 오류·키보드 모달 동작을 확인합니다.
