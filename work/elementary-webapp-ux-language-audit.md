# 학생 언어 감사

- 점검일: 2026-08-31
- 기준: 초등 5~6학년이 첫 읽기에서 다음 행동과 성공 조건을 이해할 수 있는가

## 유지

- “필수 사실을 모두 눌러 잠가야 다음 단계로 넘어갈 수 있어요.”처럼 행동과 완료 조건이 함께 제시됨
- “아직 채우지 못한 요소”, “문장 다시 고치기”처럼 회복 행동이 직접적으로 드러남
- 목적·독자·사실을 일관된 단어로 반복해 개념 연결을 돕음

## 수정

| 현재 문구 | 문제 | 추천 문구 |
| --- | --- | --- |
| `최초 MVP 설계` | 제품 개발 용어가 학생에게 의미 없음 | `처음 만들기` |
| `복수 정답 피드백` | 추상적인 평가 용어 | `여러 가지 알맞은 답과 도움말` |
| `정확한 콘텐츠 조합` | 무엇을 개선했는지 행동이 보이지 않음 | `목적에 꼭 필요한 표현과 알맞은 문장 조각` |
| `gi-pulse 단계 안내·모바일·키보드 접근성 적용` | 구현 용어가 학생에게 의미 없음 | `단계 버튼을 더 쉽게 찾고 작은 화면과 키보드에서 편하게 사용할 수 있도록 개선` |
| `모달 키보드 접근성·44px 터치 영역·결과 복사 실패 안내 개선` | 기술 수치와 UI 전문 용어 노출 | `업데이트 창과 버튼 조작, 결과 복사 안내를 더 편하게 개선` |
| `t1 근거 틀 선택` | 내부 식별자 노출 | `첫 번째 근거 틀 선택: …` |
| 서로 다른 입력칸의 `독자 빈칸` | 어느 근거 틀의 입력인지 이름만으로 구별하기 어려움 | `1번째 근거 틀의 독자 빈칸`처럼 순서 포함 |
